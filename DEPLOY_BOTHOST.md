# Деплой бота «Швейный HUB» на Bothost.ru

Бот разворачивается как **Python-приложение** (long-polling, вебхуки не нужны).

## 1. Создание приложения
1. Зарегистрируйтесь на [bothost.ru](https://bothost.ru) → «Создать приложение».
2. Язык/тип: **Python** (рекомендуется Python 3.11+; в проекте использован 3.11).
3. Загрузите репозиторий (git или архивом). Файл `.venv/` в архив не включать —
   зависимости будут установлены из `requirements.txt`.

## 2. Точка входа (Startup command)
В настройках приложения в поле команды запуска укажите:

```bash
bash start.sh
```

Скрипт `start.sh`:
- поднимает веб-админку Flask на порту из переменной `PORT`, которую выдаёт Bothost
  (если `PORT` нет — на 8080);
- отключает локальный сокет-замок экземпляров (`DISABLE_INSTANCE_LOCK=1`);
- запускает `python main.py` (бот + админка в одном процессе).

Зависимости Bothost ставит сам командой:

```bash
pip install -r requirements.txt
```

(выполняется автоматически при сборке — убедитесь, что поле install-команды не пустое).

## 3. Переменные окружения (в панели «Переменные окружения»)

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен Telegram-бота от @BotFather |
| `ADMIN_ID` | да | Числовой ID администратора |
| `GIGACHAT_CREDENTIALS` | нет | Креды GigaChat для ИИ-ответов; без них ИИ-функции отключаются (бот работает) |
| `DATABASE_URL` | нет | По умолчанию `sqlite:///workshop.db`. Для надёжности подключите PostgreSQL-базу Bothost: `postgresql://user:pass@host:5432/dbname` |
| `FLASK_PORT` | нет | Ставится скриптом из `PORT` автоматически |

Шаблон для локального запуска: `.env.example` → скопировать в `.env`.

## 4. База данных
- **SQLite (по умолчанию):** файл `workshop.db` создаётся в корне приложения при
  первом запуске. Минус: теряется при пересборке контейнера без persistent-диска.
  Если Bothost даёт постоянный диск — укажите путь на него через `DATABASE_URL`
  (например `sqlite:////storage/workshop.db`).
- **PostgreSQL (рекомендуется для продакшена):** создайте БД в панели Bothost,
  пропишите `DATABASE_URL` — таблицы инициализируются автоматически (`init_db()`).

## 5. Проверка после запуска
1. Логи приложения: инициализация БД, затем `run_polling` без ошибок.
2. Напишите боту `/start` — должно открыться главное меню.
3. Веб-админка доступна по домену/порту, который назначил Bothost (тот же `PORT`).

## Частые проблемы
- **Conflict: terminated by other getUpdates** — старый экземпляр бота где-то ещё
  запущен (локально/на Replit). Остановите его; `main.py` использует
  `drop_pending_updates=True`.
- **Бот молчит после деплоя** — проверьте `BOT_TOKEN` в переменных окружения
  (файл `.env` на хостинг не загружается и игнорируется git).
- **Перезапуски по таймауту памяти** — увеличьте лимит RAM в тарифе или перейдите
  на внешний PostgreSQL вместо SQLite.
